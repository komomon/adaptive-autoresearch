# Codex Adapter

推荐以 `codex-autoresearch2` 为主运行时参考。

建议直接吸收：

- foreground / background / resume
- launch/runtime/state/context/lessons 分层
- helper authoritative state
- parallel batch protocol
- session resume protocol

可以选择性吸收：

- dashboard
- MCP tool contract
- quality-gap loop
- finalize 体验

该 adapter 的核心职责是把 Codex 的执行方式映射到统一 contract，而不是修改 grading 或 lessons 语义。
