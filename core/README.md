# Core

`core` 只放与漏洞类型无关、与运行时无关、但对 autoresearch 稳定性至关重要的公共能力：

- session / state / results / lessons
- packet / checkpoint
- keep / discard / crash / refine / pivot / blocked
- shared schema contract
- scoreboard
- meta-loop 边界

这里后续适合继续补：

- state helper
- packet executor
- keep/discard controller
- lesson ledger
- scoreboard aggregator
